# マルチメディア研究会2026夏

電気通信大学マルチメディア研究室（旧尾内研）の研究会の案内ページです。
2026年9月20日（日）、電気通信大学 西5号館にて開催します。
12:30受付開始、13:00開始、18:00終了。参加費無料、終了後に懇親会を予定しています（実費負担の予定）。
HTMLとCSSのみで構成しており、ビルドやパッケージのインストールは不要です。

## ファイル

- `index.html`: 案内本文。日時、会場、ゲスト講演、参加方法、実行委員長、オーガナイザはこちらを編集します。
- `styles.css`: 配色とレイアウト。スマートフォン表示・印刷に対応しています。
- `.nojekyll`: GitHub Pagesで静的ファイルをそのまま配信するためのファイルです。

## ローカルで確認

`index.html` をブラウザで開くと確認できます。

## GitHub Pagesで公開

1. 公開先のGitHubリポジトリのルートに、このフォルダのファイルをアップロードします。
2. リポジトリの **Settings → Pages** を開きます。
3. **Build and deployment → Source** で **Deploy from a branch** を選択します。
4. ファイルを置いたブランチ（通常は `main`）と **/ (root)** を選び、保存します。
5. デプロイ完了後、Pages設定に表示されるURLで確認します。

通常のプロジェクトリポジトリでは、URLは `https://<ユーザー名>.github.io/<リポジトリ名>/` になります。
CSSは相対パスで参照しているため、リポジトリ名による変更は不要です。
